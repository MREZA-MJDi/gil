# Homepage hero image

Upload your own transparent food cutout from your computer to this folder and name it exactly:

- `hero-food.png`

The homepage reads it from `/images/hero/hero-food.png`. A transparent PNG works best so the food sits cleanly over the blush wave and charcoal background. Suggested size: 1200 × 1200 px or larger; keep it optimized where possible.

Until this file exists, the page automatically falls back to its current sample food image.
